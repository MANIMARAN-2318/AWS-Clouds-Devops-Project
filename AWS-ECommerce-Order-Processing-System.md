# AWS E-Commerce Order Processing System

## Project Overview
A serverless e-commerce order processing system built using AWS services to automate order handling, notifications, and background processing.

## AWS Services Used
- Amazon API Gateway
- AWS Lambda
- Amazon DynamoDB
- AWS Step Functions
- Amazon SQS
- Amazon SNS
- Amazon EventBridge
- Amazon CloudWatch
- AWS IAM
- AWS KMS
- AWS WAF

## Architecture
Customer → API Gateway → Lambda → DynamoDB → Step Functions → SQS → Lambda → SNS

## Key Features
- Serverless order processing
- DynamoDB order storage
- Step Functions workflow automation
- SQS-based asynchronous processing
- SNS email notifications
- EventBridge event integration
- IAM-based access control
- CloudWatch monitoring
- Data encryption

## Technologies
AWS Cloud | Serverless | Python | DynamoDB | Lambda | API Gateway | SQS | SNS | Step Functions | EventBridge | IAM | CloudWatch
